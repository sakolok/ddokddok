# 보호자 알림 기준

똑똑똑의 보호자 알림은 진단 알림이 아니라 변화 관찰 알림이다. 목적은 시니어 사용자의 대화와 자가문진에서 반복적인 우려 신호가 보일 때 보호자가 추가 확인을 하도록 돕는 것이다.

대화 기반 KDSQ 알림은 세션 종료 후 비동기 분석에서 처리된다. 분석 Lambda는 최근 7일 KDSQ 응답을 조회하고, 우려 응답 수를 계산한다. 현재 운영 기준은 우려 응답 수가 6회 이상이면 보호자 알림 대상으로 판단한다. 같은 세션에서 이미 알림을 보낸 경우 중복 발송을 막기 위해 alert_sent 값을 저장한다.

대화 기반 보호자 알림 제목은 `Elder Voice Companion: 변화 관찰 알림`이다. 본문은 `최근 하루 기준 KDSQ 우려 응답이 기준치를 넘어 변화 신호가 관찰되었습니다. 추가 확인을 권장드립니다.`로 발송된다. 구현상 판단 데이터는 최근 7일 응답이고, 문구는 현재 서비스 메시지를 그대로 사용한다.

자가문진 알림은 사용자가 15개 문항을 제출할 때 처리된다. 최근 7일 자가문진 점수 평균이 6점 이상이면 보호자에게 알림을 보낸다. 자가문진 보호자 알림 제목은 `Elder Voice Companion: 자가문진 변화 관찰 알림`이다. 본문은 `최근 1주일 자가문진 평균 점수가 기준치를 넘어 변화가 관찰되었습니다. 추가 확인을 권장드립니다.`로 발송된다.
