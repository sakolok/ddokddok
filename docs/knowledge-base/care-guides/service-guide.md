# 서비스 안내

똑똑똑은 시니어 사용자가 음성으로 일상과 감정을 이야기하고, 보호자가 대화와 활동 신호를 참고할 수 있게 만든 AWS 서버리스 기반 음성 AI 케어 서비스다.

주요 흐름은 다음과 같다.

1. 사용자는 브라우저에서 음성으로 말한다.
2. 음성 입력은 Amazon Transcribe를 기본 STT 경로로 사용한다.
3. API Gateway와 Lambda가 인증된 요청을 받아 대화 이력, KDSQ 정책, 필요한 경우 Knowledge Base 검색 결과를 구성한다.
4. Amazon Bedrock이 한국어 대화 응답을 생성한다.
5. Amazon Polly Seoyeon generative 음성이 응답을 읽어준다.
6. 대화, KDSQ 응답, 자가문진, 활동 로그는 DynamoDB에 저장된다.
7. 세션 종료 후 SQS 기반 비동기 분석 Lambda가 보호자 알림 필요 여부를 판단하고, 기준을 넘으면 SNS 이메일 알림을 보낸다.

Knowledge Base는 모든 대화에 무조건 쓰지 않는다. 사용자가 KDSQ, 자가문진, 보호자 알림, 점수 기준, 서비스 동작처럼 사실 설명이 필요한 질문을 했을 때만 검색한다. 가족 걱정, 우울감, 짧은 대답처럼 정서적 흐름이 중요한 대화에서는 검색보다 공감과 안전한 후속 질문을 우선한다.
